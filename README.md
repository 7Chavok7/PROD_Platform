# ProdPlatform — Производственная платформа

## Описание
Система управления производственными заказами для предприятий с единичным и мелкосерийным производством.

## Технологии
- Python 3.12
- Django 5.2.16
- Django REST Framework 3.16+
- PostgreSQL 15
- Redis 3 (для Celery)
- Bootstrap 5 + Alpine.js
