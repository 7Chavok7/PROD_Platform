# 🏭 ProdPlatform — Модульная производственная платформа

[![Django](https://img.shields.io/badge/Django-5.2-green.svg)](https://www.djangoproject.com/)
[![Python](https://img.shields.io/badge/Python-3.12-blue.svg)](https://www.python.org/)
[![License](https://img.shields.io/badge/License-Proprietary-red.svg)]()

**ProdPlatform** — это гибкая, модульная система управления производственными заказами. Она подходит как для микропредприятий с 3 сотрудниками, так и для крупных заводов с сотнями работников.

## 🎯 Ключевые принципы

1. **Модульность** — каждый функциональный блок (кадры, заказы, склад, логистика) — это опциональный модуль.
2. **Гибкость** — система подстраивается под активные модули. Если нет модуля "Сотрудники" — вы вводите ФИО вручную.
3. **Расширяемость** — вы можете включить модуль в любой момент, и система автоматически адаптирует интерфейс.
4. **Универсальность** — работает как на одном компьютере, так и в корпоративной сети.

## 📦 Модули

| Модуль            | Назначение                            | Обязательность |

| **`orders`**      | Управление заказами и этапами         | ✅ **Обязательный** |.
| **`employees`**   | Кадровый учёт, матрица квалификаций   | ⚠️ Опциональный |.
| **`customers`**   | Учёт контрагентов                     | ⚠️ Опциональный |.
| **`warehouse`**   | Учёт материалов и склада              | ⚠️ Опциональный |.
| **`logistics`**   | Логистика и аутсорсинг                | ⚠️ Опциональный |.

====================================================================================
1. Установка
git clone https://github.com/7Chavok7/PROD_Platform.git
cd PROD_Platform
python -m venv venv
source venv/bin/activate  # Windows: venv\Scripts\activate
pip install -r requirements.txt

2. Настройка
cp .env.example .env
# Отредактируйте .env (укажите настройки БД, Redis, секретный ключ)

3. Миграции
python manage.py migrate
python manage.py createsuperuser

4. Запуск
python manage.py runserver

🏗️ Архитектура
core/               # Ядро (абстрактные модели, проверка модулей)
core_app/           # Утилиты (миксины, декораторы)
employees/          # Модуль "Кадры" (опциональный)
customers/          # Модуль "Контрагенты" (опциональный)
orders/             # Модуль "Заказы" (обязательный)
warehouse/          # Модуль "Склад" (опциональный)
logistics/          # Модуль "Логистика" (опциональный)

🎯 Сценарии использования

Сценарий 1: Микропредприятие (3 человека, 1 ПК)

Активные модули: только orders
Режим работы: все данные (сотрудники, заказчики, материалы) вводятся вручную
Интерфейс: максимально простой, без лишних справочников

Сценарий 2: Малое предприятие (10–20 человек)

Активные модули: orders + employees + customers
Режим работы: сотрудники и контрагенты выбираются из справочников
Интерфейс: стандартный, с фильтрами и матрицей квалификаций

Сценарий 3: Крупное предприятие (100+ человек)

Активные модули: все (orders, employees, customers, warehouse, logistics)
Режим работы: полный учёт, интеграция с 1С, датчики, логистика
Интерфейс: расширенный, с отчётами и аналитикой
